# WhyWait 拖延拦截器

这是一个 Manifest V3 浏览器扩展，用于把持续逃避行为转交给 WhyWait 行动救援台。

## 本地安装

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择当前 `browser-extension` 目录。
5. 在扩展弹窗中确认救援页地址，本地开发默认是 `http://localhost:3000/rescue`。

## 网页小精灵

扩展开启“网页小精灵”后，小精灵会出现在普通网页右下角。它可以在页面上拖动，点击后会展开当前任务和微行动。

- 普通网页：待机陪伴。
- 配置的拖延网站：显示停留分钟数并逐渐进入警报状态。
- 达到阈值：小精灵与拦截层同时提示，可一键打开行动救援台。
- 点击“隐藏”：关闭所有网页上的小精灵，可在扩展弹窗重新开启。

小精灵运行在浏览器内。关闭 WhyWait 页面后仍会保留在其他网页上，但无法覆盖浏览器以外的桌面应用；系统级桌面浮窗需要后续 Electron 或 Tauri 版本。

## 本地演示

1. 先启动 WhyWait：`npm run dev`。
2. 打开一个配置在拦截域名列表中的网站。
3. 在扩展弹窗中把停留阈值改为 1 分钟，或点击“测试拦截”。
4. 拦截层出现后，点击“开始 5 分钟”会打开行动救援台。

拦截器只把设置、停留时间和拦截次数保存在 `chrome.storage.local`，不会上传浏览历史。
